# ACE2 vs ERA5 heat/cold extreme skill

Lag-initialized ensemble forecasting experiments with the ACE2-ERA5 model,
evaluated against ERA5 reanalysis for seasonal heat extremes (JJA, "HHE") and cold
extremes (DJF). The core question is whether ACE2, run as a 25-member lagged
ensemble, can skillfully predict where and how often a season will see
extreme-temperature days, and how that skill compares to (or is explained by)
remote SST forcing and spatial clustering of the prediction grid.

This is a working research repo, not a packaged library — scripts are run
directly and mostly write their outputs to `outputs/`.

## Layout

```
src/hiro_ace_pipeline/   installable package: config, path layout, planning of
                         lag-ensemble cases, ERA5 baselines, extremes computation,
                         figure generation (the "hiro" pipeline, used by the
                         scripts/run_*_inference*.py + postprocess scripts)
scripts/                 everything else — data prep, inference launchers,
                         postprocessing, skill maps, clustering, SST teleconnections
data/lag_data/           initial conditions + forcing files for ACE2 (not tracked)
checkpoint/              ACE2-ERA5 model weights (not tracked, ~3.4 GB)
runs/                    raw per-member inference output, one dir per init year
                         (not tracked, very large)
combined/, combined_djf/ runs/ collapsed into one NetCDF per init year (not tracked)
outputs/lag_may/         JJA (summer heat extreme) analysis outputs and figures
outputs/lag_nov/         DJF (winter cold extreme) analysis outputs and figures
logs/                    pipeline run logs (not tracked)
CLUSTER_SETUP.md         how to move the model + data to a separate GPU cluster
                         and run inference there
ace2_jja_heatextremes.tex  write-up of the JJA results
```

`data/`, `runs/`, `outputs/`, `combined*/`, `checkpoint/`, and `logs/` are all
gitignored — they range from gigabytes to hundreds of gigabytes and are
regenerated by the scripts below, not meant to live in version control.

## Setup

```bash
conda env create -f environment.yml
conda activate ace2
```

`fme` (the ACE2 inference package) and the HF Hub client are installed via pip
inside the conda env since they're not on conda-forge. Model checkpoint and
input data are not in this repo — see `CLUSTER_SETUP.md` for where they live
and how to fetch/copy them.

## Pipeline, roughly in order

1. **Prep initial conditions / forcing** — `make_lag_ics_*.py`,
   `download_forcing.py`, `convert_forcing_ace2era5.py`.
2. **Run inference** — `run_lag_inference*.py` launches the 25-member lagged
   ensemble (round-robin across however many GPUs you have); see
   `CLUSTER_SETUP.md` for the multi-GPU flags and `--skip-existing` resume
   behavior.
3. **Combine** — `combine_lag_*.py` collapses each member's raw output into
   one NetCDF per init year under `combined/` or `combined_djf/`.
4. **Postprocess** — `postprocess_jja_lag.py` / `postprocess_djf_lag.py` compute
   daily extremes against ERA5-derived thresholds.
5. **Seasonal skill** — `seasonal_jja_skill.py` / `seasonal_djf_skill.py` (and
   the `_sliding7d`/`_no_loo` variants) compute the leave-one-out, sliding-window
   90th-percentile threshold per init year and turn it into a seasonal
   extreme-frequency time series and a Pearson r / Kendall τ skill map of
   ACE2 vs ERA5. `plot_jja_seasonal*.py` renders the CONUS/global figures.
6. **Spatial clustering** — `cluster_skill_analysis*.py` groups grid points
   (K-means, SOM, and REDCAP — Ward clustering under a spatial contiguity
   constraint) and recomputes skill at the cluster level, since aggregating
   over space before correlating cancels noise and tends to raise skill;
   the point of comparing methods is to see how much of that is just
   aggregation versus a real spatially coherent signal.
7. **SST teleconnections** — `sst_teleconnection_jja*.py` correlates/regresses
   detrended SST against detrended heat-extreme frequency (gridpoint SST vs.
   a regional extreme-frequency index, and separately a Tropical North
   Atlantic SST index regressed onto the gridded extreme-frequency field),
   for both ERA5 and ACE2, to see whether ACE2 reproduces the observed
   ocean-forcing relationship.

Most of the analysis scripts take a `--replot` flag to skip the expensive
recomputation step and just redraw figures from the cached intermediate
NetCDFs in `outputs/`.

## Naming notes

- **HHE** = "heat high extreme" (JJA hot-day frequency); the DJF analog is
  cold extremes.
- **LOO** = leave-one-out — each init year's extreme threshold is computed
  from the other 36 years only, so a year is never used to define its own
  threshold.
- **lag_may** / **lag_nov** refer to the month the lagged ensemble is
  initialized in (May → JJA target season, November → DJF target season).
